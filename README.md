### 📊 Featured Projects

**[synchrony-call-forecasting](https://github.com/shrugbug/synchrony-call-forecasting)** — *Python*
Prophet + XGBoost pipeline to forecast call-center demand across four business
portfolios (Synchrony × AWS Datathon). Disciplined iteration improved the competition

**[hmda-mortgage-disparity](https://github.com/shrugbug/hmda-mortgage-disparity)** — *R*
Bayesian analysis of racial disparity in mortgage approvals on federal HMDA data, using

vs. 43.9% for white speakers (**1.82× disparity**); showed calibration cut the gap 33%
without retraining.

**[f1-shiny-dashboard](https://github.com/shrugbug/f1-shiny-dashboard)** — *R*
Interactive R Shiny dashboard for 2023 Formula 1 performance, built on a modular

**[categorical-data-analysis](https://github.com/shrugbug/categorical-data-analysis)** — *R*
